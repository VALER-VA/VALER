# VÄLER | قالب متجر أقمشة رجالية

قالب واجهة أولي احترافي باسم فالِر VÄLER، مصمم باتجاه بصري فاخر وهادئ ومناسب لمتجر متخصص في الأقمشة الرجالية.

## الصفحات
- الرئيسية
- التصنيفات
- صفحة كل تصنيف
- صفحة المنتج
- السلة
- إتمام الطلب
- عن فالِر
- تواصل معنا

## الهوية
- تم استخدام الشعار المرفق في `assets/logo.jpg`.
- تم استخدام الخط المرفق `fonts/Pen-Kufi.ttf`.
- الألوان الأساسية: الأسود الفحمي، العاجي، والذهبي/البني.
- الخلفية مبنية بـ CSS بدون صور خارجية، لتكون خفيفة وسهلة التعديل.

## ملاحظة مهمة لسلة
هذا المشروع هو **واجهة Front-end مستقلة كنقطة انطلاق**. عند نقله إلى منصة سلة، يتم تحويل بنية HTML إلى ملفات الثيم/قوالب سلة وربط المنتجات والتصنيفات والسلة والدفع ببيانات سلة بدل البيانات التجريبية الموجودة في `js/app.js`.

المنتجات الحالية تجريبية فقط لتوضيح شكل المتجر والتصنيفات.
